# Sprite overrides

Drop `<agentId>.png` here (for example `sektor.png`) to replace the generated character.

- Size: 64 x 72 px, frames of 16 x 24 px, transparent background, feet on the bottom row.
- Row 0: walk cycle facing the camera, left-down (SW), 4 frames.
- Row 1: walk cycle facing away, left-up (NW), 4 frames.
- Row 2: typing at the desk, facing the camera, frames 0-1 (columns 2-3 unused).
- Right-facing directions (SE, NE) are the same frames mirrored.

Wrong size or missing file: the generated sprite is used. Reload the page after adding a file.
