# Content QA (CPO)

Save as `qa-<post id>-v<n>.md`. Score each check 1 (pass) or 0 (fail). **Pass = 8/10 or more and no fail on a blocking (●) check.**

| # | Check | ● | Score | Note / exact fix |
|---|---|---|---|---|
| 1 | Matches the brief (goal, audience, platform, format, KPI) | | | |
| 2 | Hook works in 2 s / first line | | | |
| 3 | Brand voice and brand kit | ● | | |
| 4 | Spelling and grammar (EN/AR) | | | |
| 5 | Facts, numbers, claims sourced | ● | | |
| 6 | Rights: music, faces, logos, fonts, third-party content | ● | | |
| 7 | AI assets labelled, prompt recorded | | | |
| 8 | Platform specs and safe zones | ● | | |
| 9 | Accessibility: captions, alt text, contrast | | | |
| 10 | One clear CTA | | | |

**Result:** PASS / FAIL · Total: x/10 · Blocking fails: …

A FAIL lists exact fixes, the owner of each fix, and goes back to them. Re-review the new version as v<n+1>.
