# Carousel design (CCO)

Save as `carousel-<post id>.md`.

## Structure (5 to 10 slides, 4:5 portrait for Instagram)
1. **Cover:** the hook in large type, one visual, a reason to swipe.
2. **Value slides:** one point per slide, headline + max 2 short lines.
3. **Recap or proof.**
4. **CTA slide.**

## For each slide give
Headline, supporting text, visual (photo, illustration, AI image prompt), layout (where text sits), colours and fonts from the brand kit.

## Rules
- Consistent grid and margins on every slide; text never in the outer edge band.
- Minimum readable size on a phone; strong contrast (check WCAG 4.5:1 for body text).
- Number slides only when order matters.
