# Captions (CMO)

Save captions in the post's file (`post-<post id>.md`) under **Caption**.

## Shape
1. **First line:** the hook; it is all that shows before "more". Front-load the value.
2. **Body:** 1 to 4 short lines; line breaks for scanning.
3. **CTA:** one action tied to the KPI (save, share, comment a word, link in bio, book).
4. **Hashtags:** 3 to 8 relevant ones (mix of niche and broader); none that are banned or unrelated.

## Per platform
- Instagram / TikTok: conversational, emoji only if the brand uses them.
- LinkedIn: professional, insight first, fewer hashtags.
- X: one idea, short.
Check each platform's current character limit before finalising; do not guess it.

## Arabic
Write natively, not translated; keep brand terms consistent; check right-to-left punctuation.
