# Campaign orchestration (CEO)

## Steps
1. **Restate the request** in one line: client, goal, platforms, deadline, what "done" means.
2. **Brief first.** Assign Zurub the brief. Nothing else starts until `brief-<client>-<id>.md` exists.
3. **Create in parallel** once the brief exists: Nedal (copy, scripts), Aktham (visual direction). Name the brief file in each assignment.
4. **Produce.** Assign Rajaie the production pack, naming the script and visual files.
5. **QA.** Assign Razan the review, naming every asset file. Only a QA file with PASS moves forward.
6. **Approve.** read_file the QA file and the assets. Approve only if QA passed and the assets match the brief.
7. **Hand to the owner** with: file list, what to publish where and when, open risks.

## Assignment template
> Client: … · Post id: … · Input files: … · Deliverable: <file name> · Done when: …

## Weekly priorities
At most five, each tied to a client and a KPI from a brief. Drop a priority before adding a sixth.

## Never
Publish, schedule on live accounts, spend, contact clients, or approve without a passing QA file.
