# Hooks (CMO)

Write 10, keep the best 3, and say why.

## Patterns
- **Problem:** "Still doing X the hard way?"
- **Surprise / contrast:** "We doubled X by doing less."
- **How-to:** "3 ways to … in 30 seconds."
- **Mistake:** "Stop … (do this instead)."
- **Behind the scenes:** "What really happens when …"
- **Proof:** "How [client] got [result]" (only with a real, sourced result).
- **Question:** a question the audience is already asking.

## Rank by
Clarity in under 2 seconds, specificity, relevance to the brief's audience, honesty (no clickbait the content does not deliver).
