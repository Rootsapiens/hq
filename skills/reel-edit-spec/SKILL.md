# Reel edit spec (CTO)

Save as `edit-<post id>.md`.

- **Inputs:** script file, visuals file, footage or AI clips list.
- **Timeline table:** timecode, clip, cut type, on-screen text, caption, sound.
- **Captions:** burned in, style from the brand kit, inside safe zones.
- **Music:** mood, tempo, and a licensed source (platform library or licensed stock). No unlicensed tracks.
- **AI clips / voice:** the exact prompt or voice settings, labelled **AI-generated**.
- **Export:** 9:16 vertical, 1080x1920, the frame rate of the footage; check the platform's current length and size limits.
- **File name:** `<client>_<post id>_<platform>_v<n>.mp4`.
