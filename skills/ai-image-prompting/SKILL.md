# AI image prompting (CCO)

Save prompts in `visuals-<post id>.md`.

## Prompt recipe
`[subject + action], [setting], [composition and camera: shot type, angle, lens feel], [lighting], [style and medium], [brand colours], [mood], aspect ratio [9:16 | 4:5 | 1:1]`
**Negative:** text artefacts, extra fingers, warped logos, watermarks, off-brand colours.

## Rules
- Never prompt for real people's likeness, celebrities, other brands' logos or copyrighted characters.
- Do not ask the model to render body text; add text in design.
- Produce 3 variations with one change each (angle, lighting or palette) so the owner can choose.
- Record the exact prompt and mark the asset **AI-generated** in its file.
